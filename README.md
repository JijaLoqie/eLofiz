## Об Авторе

**Дмитрий Краскоский** — Полнофункциональный разработчик с более чем 2 годами опыта в коммерческой разработке. Специализируюсь на **TypeScript**, **React** и современном веб-стеке. Имею глубокое понимание архитектуры как фронтенда, так и бэкенда. Дважды реализовывал примитивные версии **Redux** и **React** с нуля. Недавно возглавил полную переработку монолитного приложения для компании "Ступор", что позволило сократить размер кода в 4 раза и уменьшить вес приложения с 1 ГБ до 50 МБ. Увлекаюсь нестандартными решениями, интеграцией ИИ и созданием интерфейсов с продуманным UX/UI.

## Технологический Стек

**eLofiz** построен на современных веб-технологиях:
- **Frontend Framework:** React с Redux для управления состоянием
- **Стилизация:** Tailwind CSS
- **Язык:** TypeScript

*Приложение было изначально прототипировано на ванильном TypeScript и CSS, затем переработано в надежное решение с использованием React + Redux + Tailwind для улучшенной поддерживаемости и масштабируемости.*

## Что такое eLofiz?
![telegram-cloud-photo-size-2-5269230999210497522-y](https://github.com/user-attachments/assets/cf08b1fb-1b66-4cd6-9484-de01a69674c6)


**eLofiz** — это ваш персональный архитектор атмосферы. В мире, где окружение влияет на производительность и благополучие, eLofiz предоставляет вам полный контроль над кастомизацией вашего рабочего пространства.

Независимо от того, работаете ли вы над сложным проектом, учитесь или просто хотите расслабиться, eLofiz создает *именно ту* атмосферу, которая вам нужна.

---

## Основная Концепция

Я верю, что ваша цифровая среда должна адаптироваться под *ваши* нужды. eLofiz предоставляет вам полный творческий контроль над вашим рабочим пространством.

Каждый элемент можно кастомизировать. Каждая деталь имеет значение. Каждое взаимодействие способствует созданию идеального настроения.

## Основные Возможности

### 🎨 **Персонализированные Пространства**
Создавайте неограниченное количество пользовательских пространств для различных настроений и задач. Переключайтесь между ними без задержек, мгновенно изменяя свое умственное состояние.
![telegram-cloud-photo-size-2-5273734598837866946-y](https://github.com/user-attachments/assets/d3c8af26-47a3-48c1-a96c-318db72812e7)


### 🎵 **Погружающаяся Звуковая Атмосфера**
Кураторируйте свою звуковую среду с точностью. Будь то окружающие звуки, музыка для концентрации или вдохновляющие треки — создавайте звуковую атмосферу, которая поддерживает ваш поток работы.

### ⏱️ **Инструменты Управления Временем**
Интегрируйте таймеры и расписание в ваше рабочее пространство. Управляйте своими сессиями и поддерживайте оптимальный темп.

### 🎮 **Динамические Виджеты и Кастомизация**
Комбинируйте интерактивные элементы, чтобы создать уникальное рабочее пространство. Настраивайте виджеты по своему вкусу и рабочему процессу.
![telegram-cloud-photo-size-2-5273734598837866948-y](https://github.com/user-attachments/assets/5028ccda-fa4b-45f9-9e66-b090c6fdb1ad)


### ✨ **Атмосферные Эффекты**
Трансформируйте внешний вид и ощущение вашего пространства с помощью визуальных эффектов, которые улучшают концентрацию.

### 🎯 **Окружения на Основе Настроения**
Переключайтесь между заранее установленными или пользовательскими окружениями для различных психических состояний:
- **Режим Работы** — для интенсивной работы
- **Режим Обучения** — для учебы
- **Режим Релаксации** — для отдыха
- **Пользовательские Режимы** — созданные вами

## Почему eLofiz?

В цифровом мире мы часто забываем о том, как окружение влияет на наше психическое состояние. eLofiz заполняет эту пустоту.

Это не просто приложение для отвлечения. Это осознанный подход к дизайну. Каждый звук, каждый визуальный элемент, каждый таймер работают в гармонии для достижения ваших целей и повышения благополучия.

## Начало Работы

### Установка и Настройка

Убедитесь, что у вас установлен [Bun](https://bun.sh) на вашу систему.

### Запуск Приложения

Для запуска сервера разработки просто выполните:

```bash
bun run dev
```
